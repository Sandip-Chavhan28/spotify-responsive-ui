# 🎵 Spotify UI Clone

A Spotify-inspired web UI clone built using **HTML and CSS**, designed to replicate the look and feel of Spotify’s web player interface.

---

## 🚀 Project Overview

This project focuses on building a clean and responsive music streaming UI similar to Spotify.  
It includes a sidebar navigation, playlist cards, and a fixed bottom music player.

---

## ✨ Features

- 🎧 Spotify-like modern UI
- 📌 Fixed bottom music player
- 📱 Responsive layout
- 🧭 Sidebar navigation (Home, Search, Library)
- 🎵 Playlist & album cards
- 🎚 Custom progress bar design

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome Icons**
- **Google Fonts (Montserrat)**
